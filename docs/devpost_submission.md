## 💡 Inspiration
The world doesn't need another generic AI wrapper or single-prompt chatbot. Every single day, product leaders, founders, and marketing managers spend 15–25 hours manually browsing competitor changelogs, tracking pricing tweaks, and sifting through G2 and Reddit reviews to understand market positioning.

By the time a team discovers a competitor's pricing increase or feature shift through quarterly reports, market share has already been lost. We asked ourselves: **What if an autonomous swarm of specialist AI agents could continuously monitor the market, cluster customer sentiment, perform SWOT analysis, and automatically synthesize actionable executive counter-playbooks with direct ROI projections?**

That vision led to **OmniPulse AI**.

---

## ⚡ What It Does
**OmniPulse AI** is an autonomous SaaS intelligence engine that converts messy competitor web telemetry into structured, executive-ready strategy.

### Core Features:
1. **🛰️ Autonomous Multi-Agent Swarm:** Orchestrates 4 specialized agents in parallel:
   - **Recon Scout Agent:** Scrapes competitor pricing tiers, sitemaps, and changelog endpoints.
   - **Sentiment Lens Agent:** Ingests reviews across G2, TrustPilot, and Reddit to cluster real customer friction vectors.
   - **StratOps Moat Agent:** Calculates price elasticity, SWOT matrices, and competitive threat indices.
   - **Action Dispatch Agent:** Formulates tactical playbooks and sprint backlogs with estimated ARR impact.
2. **📊 Executive Mission Control:** Live threat gauges, pricing parity deltas, customer NPS tracking, and multi-dimensional Capability Radar benchmarks.
3. **🏢 Deep Competitor Battlecards:** Side-by-side feature parity matrices, strengths vs. vulnerabilities, and recent competitor movements.
4. **🎯 Autonomous Playbook Studio:** Ready-to-execute counter-attack playbooks (e.g. *Flat Team Tiering Campaign*, *Instant Migration Bridge Tooling*) with one-click dispatch to Slack and Jira.
5. **📑 One-Click Executive Briefing Dossier:** Generates formatted Markdown and print-ready PDF executive dossiers for board meetings.
6. **🌐 Multi-Sector Intelligence:** Pre-loaded with high-fidelity datasets spanning AI Workspace (Notion vs. Linear), Fintech (Stripe vs. Adyen), and Cloud Databases (Supabase vs. Neon), alongside custom domain scanning capabilities.

## 🛠️ How We Built It
- **Frontend & Design System:** Pure HTML5, Modular ES6+ JavaScript, and a bespoke CSS design system featuring cyber-dark glassmorphism, responsive CSS Grid/Flexbox layouts, glowing ambient orbs, and micro-interactions.
- **Visual & Charting Engine:** Custom SVG & Canvas data visualizer with dynamic radar polygons and smooth circular gauges with zero heavy external charting dependencies.
- **Agent Swarm Architecture:** Asynchronous event-driven orchestrator managing state transitions, progress telemetry, and streaming syntax-highlighted reasoning logs.
- **Inference & Execution:** Dual-mode execution engine featuring a deterministic high-fidelity simulation engine for instantaneous judging evaluation, with optional live LLM API keys (OpenAI GPT-4o, Claude 3.5, Gemini 2.0).

---

## 🧗 Challenges We Ran Into
- **Orchestrator State Synchronization:** Designing an intuitive visual representation of parallel multi-agent reasoning without overwhelming the user interface. We solved this with an interactive DAG agent grid and an integrated terminal log stream.
- **Meaningful Intelligence vs. Data Dumps:** Raw web scraping often produces noisy text. We engineered strict structured JSON schema extraction so agents output clean, normalized metrics and actionable sprint items rather than vague paragraphs.
